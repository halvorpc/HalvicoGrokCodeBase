# Wine Besties — Shopify Setup Pack

Practical copy + checklist for launching **Wine Besties** (Halvico) on Shopify.

| Item | Value |
|------|--------|
| Store (temp) | `szrfry-ar.myshopify.com` |
| Custom domain | `www.winebesties.com` (GoDaddy) |
| Brand vibe | Elegant but approachable wine + cheese pairings — warm “besties” energy, still knowledgeable |

> **Note:** Cloudflare may block automated browsers in Shopify admin. Apply branding, domain, theme, and blog content yourself using the files in this pack.

## Order of operations

1. **Store basics** — name, colors, logo placeholders (see `SETUP-CHECKLIST.md`)
2. **Theme** — install Dawn (or similar free theme); set homepage sections
3. **Domain** — connect `winebesties.com` / `www` in Shopify Domains, then update GoDaddy DNS
4. **Blog** — enable Online Store → Blog; create blog **Pairings**; paste posts from `BLOG-POSTS/`
5. **Pages** — create About from `ABOUT.md`; use `HOMEPAGE-COPY.md` for hero + CTAs
6. **Polish** — set primary domain, redirects, SSL check; preview on mobile

## Brand colors (quick ref)

- **Cream** — soft background / page canvas  
- **Burgundy** — headings, accents, buttons  
- **Soft gold** — highlights, dividers, “bestie” sparkle  

Exact hex values: confirm or refine in Theme settings → Colors once Dawn is installed.
